#+title: sqlitefs

A versioned, content-addressed filesystem where a single SQLite file is both
the repository and the mountable volume.

* Features

- Single =repo.db= file is the whole repository: chunk store, DAG, and refs.
- Content-addressed storage with CIDv1 + SHA-256 (dag-pb directories,
  v1-2025 file layout, dag-cbor commits).
- Dual chunking: FastCDC for physical dedup, UnixFS for public IPFS CIDs.
- Writable FUSE mount; writes hash on =close()=, auto-commit every 60s.
- Named snapshots via =.sqlitefs/tag/<name>=, snapshot browsing via
  =.sqlitefs/refs/<name>/=, hash access via =.sqlitefs/c/<hash-prefix>/=.
- Symlinks and hard links (files only).
- Integrity checking: =fsck= verifies every CID reachable from a ref.
- Read-only Emacs dynamic module: browse/cat repos in Emacs without mounting
  (=emacs/sqlitefs.el=, dired-like browser), backed by the =sqlitefs= cdylib.

* Usage

#+begin_src sh
# create a new repository
sqlitefs init repo.db

# mount it (FUSE)
sqlitefs mount repo.db /mnt/sqlitefs

# verify integrity
sqlitefs fsck repo.db

# list refs
sqlitefs show-ref repo.db

# rebuild the directory_index view (after upgrading an old repo)
sqlitefs rebuild-index repo.db

# shell completions
sqlitefs completions bash

# list/cat files without mounting
sqlitefs ls repo.db
sqlitefs ls repo.db docs/
sqlitefs cat repo.db docs/guide.md

# copy: host→repo imports (parent dirs are created),
# repo→host extracts (host paths are /abs, ./x, ../x or ~/x),
# repo→repo copies by manifest link (chunks dedup)
sqlitefs cp repo.db ./out.md docs/readme.md
sqlitefs cp repo.db docs/readme.md ./out.md
sqlitefs cp repo.db a.txt b.txt

# rename inside the repo
sqlitefs mv repo.db docs docs-old
#+end_src

* Emacs

#+begin_src emacs-lisp
;; module auto-located via load-path (Nix: nix run .#emacs-sqlitefs),
;; or build it first: cargo build --features emacs
(require 'sqlitefs)

(sqlitefs-dired "repo.db")                     ; dired-like browsing (main ref)
(sqlitefs-visit "repo.db" "docs/readme.md")    ; read-only file buffer
(sqlitefs-show-refs "repo.db")                 ; refs with commit CIDs
#+end_src
